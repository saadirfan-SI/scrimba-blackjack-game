# Blackjack Game

A simple browser-based Blackjack game built using HTML, CSS, and vanilla JavaScript as part of Scrimba's Fullstack Developer Path.

## About the Project

This project was built to develop and reinforce my understanding of JavaScript fundamentals through an interactive browser-based game.

The game uses simplified Blackjack rules, where the objective is to reach a card total of 21 without exceeding it.

## Features

- Start a new round with two randomly generated cards.
- Draw additional cards during an active round.
- Display the player's cards and their total value.
- Display dynamic messages based on the game state.
- Detect Blackjack (21) and when the player exceeds 21.
- Prevent additional card draws after Blackjack or a bust.
- Prevent restarting while a round is active.
- Start a fresh round after winning or losing.
- Display the player's name and chip balance using a JavaScript object.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Click START GAME to begin a round.
5. Click NEW CARD to draw additional cards.

No additional dependencies or installation are required.
