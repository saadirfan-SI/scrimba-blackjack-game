# Blackjack Game

A simple browser-based Blackjack game built using HTML, CSS, and JavaScript as part of Scrimba's Fullstack Developer Path.

## About the Project

This project is helping me practise JavaScript fundamentals, including functions, conditionals, arrays, loops, and DOM manipulation.

## Features

- Display the player's cards and their total value
- Draw additional cards
- Display different messages based on the player's total
- Detect Blackjack (21) and when the player exceeds 21

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
